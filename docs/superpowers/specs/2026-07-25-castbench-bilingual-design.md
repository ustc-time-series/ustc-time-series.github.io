# CastBench 中英文双语设计说明

## 目标

将现有 CastBench 从中文为主的静态页面升级为面向国际访问者的完整中英文双语页面。语言切换必须覆盖静态内容、动态排行榜、模型详情、筛选与状态提示、页面元数据和无障碍标签，而不是只替换导航标题。

## 方案

采用单页国际化：

- 保留 `cast-bench/index.html` 作为唯一内容源，避免两份榜单、模型数据和评测协议长期漂移。
- 在主导航加入 `中文 / EN` 分段切换按钮。
- 使用 `data-i18n`、`data-i18n-html` 和属性翻译标记管理静态内容。
- 使用统一翻译字典和 `t()` 函数管理动态榜单、弹窗、筛选状态与错误提示。
- 英文深链使用 `?lang=en`，中文使用默认地址；切换时保留当前锚点。
- 优先读取 URL 语言参数，其次读取本地偏好，最后按浏览器语言选择中文或英文。
- 将语言偏好写入 `localStorage`；存储不可用时页面仍可正常切换。

## 内容范围

### 静态内容

- 页面标题、描述、Open Graph 与 X 元数据
- 跳转链接、Hero、首期规划概览和导航
- 协议演示声明、筛选器、表头、图例和无脚本说明
- Benchmark Dataset 三套数据轨道和六类领域
- 六维指标、综合分公式和指标方向说明
- 六项复现规则、四级成绩状态
- 提交与复现流程、页脚和模型详情弹窗框架

### 动态内容

- 结果数量、排序方向、领域与指标名称
- 空结果提示、前三名卡片和对比面板
- 模型详情字段、领域条形图、优势和边界说明
- 最多选择三个模型的限制与提示
- 重置、清空、关闭和 Escape 相关可访问性文案

## 国际访问

- 中文页面使用 `lang="zh-CN"`，英文模式使用 `lang="en"`。
- 提供 `hreflang="zh-CN"`、`hreflang="en"` 和 `hreflang="x-default"`。
- 英文模式更新浏览器标题、description、Open Graph 和 X 文案。
- 切换按钮使用原生 `button`、`aria-pressed` 和明确的语言名称。
- 英文深链可复制，刷新后语言不丢失。

## 数据与声明

现有模型和分数保持不变，仍全部标注为 `Protocol Demo`。英文文案必须明确说明这些数值只用于展示协议和交互，不构成正式性能声明。

## 验收

- 中文和英文按钮均存在且可通过键盘操作。
- URL 参数、本地偏好和浏览器语言按既定优先级生效。
- 所有静态板块都有英文内容。
- 12 个模型均具备英文优势和边界说明。
- 语言切换后动态榜单、模型详情和对比文案同步更新。
- 元数据、`html lang`、按钮状态和 URL 同步更新。
- 原有 14 项 CastBench 测试和全站测试继续通过。
- 新增双语回归测试先失败、实现后通过。
